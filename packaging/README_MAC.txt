HRMA — Rocket Motor Analysis (macOS Installation)
=================================================================

INSTALLATION (2 steps):

1) Drag the HRMA icon in this window onto the "Applications"
   folder next to it.

2) Open your Applications folder and launch HRMA.


IMPORTANT — IF A WARNING APPEARS ON FIRST LAUNCH:

macOS shows a warning for unsigned apps downloaded from the
internet. This is normal. Do the following:

  a) RIGHT-CLICK the HRMA icon (or hold Control and click)
  b) Choose "Open"
  c) Click "Open" again in the dialog that appears

If there is no "Open" button:
  System Settings → Privacy & Security → scroll to the bottom and
  click "Open Anyway" next to the "HRMA was blocked" message.

This approval is only needed the FIRST time.


USAGE:

- Double-click the icon; the window opens within seconds while the
  computation engines load in the background.
- HRMA opens in its own NATIVE window (macOS WebKit) —
  Chrome or any other browser is NOT required.
- When a new version is released, HRMA asks at startup; one click
  downloads the update and starts the installer.
- Closing the HRMA window also closes the program. Double-click
  the icon to open it again.
- Reports, CAD files and drawings you export are saved through a
  save dialog that starts in your Downloads folder; you choose the
  final location there. Documents/HRMA (menu: Open Output Folder)
  holds your saved projects (Documents/HRMA/projects).

If you run into problems, open an issue at https://github.com/berketez/HRMA/issues and attach this file:
Library → Logs → HRMA.log
